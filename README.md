# Neon Protocol: Breach

Portable Windows PC build: **v1.6**.

## Download and assemble

1. Download all eight files named `neon-protocol-pc-v1.6.part01` through `part08`.
2. Download `assemble-neon-protocol-v1.6.bat` into the same folder.
3. On Windows, double-click the `.bat` file. It will rebuild `neon-protocol-pc-v1.6.zip`.
4. Extract the ZIP and run `Neon-Protocol-Breach-1.6.0.exe`.

The build is split into parts because the PC package is about 80 MB.
