# Neon Protocol: Breach

Portable Windows PC build: **v1.6**.

## Easiest download

1. Download `DOWNLOAD-NEON-PROTOCOL-v1.6.bat` from this repository.
2. Put it in an empty folder on Windows and double-click it.
3. It downloads the eight build parts automatically and rebuilds `neon-protocol-pc-v1.6.zip`.
4. Extract the ZIP and run `Neon-Protocol-Breach-1.6.0.exe`.

## Manual download

Alternatively, download all eight files named `neon-protocol-pc-v1.6.part01` through `part08`, place them beside `assemble-neon-protocol-v1.6.bat`, and run the assembly file.

The build is split into parts because the PC package is about 80 MB.
